# Charts

## User-Friendly, Customizable Godot Tool for Graph Creation

### Key Features:

-   **Multi-Data Support:** Accommodates multiple data types with distinct legends and customizable colors for clear differentiation.
-   **Value Grid Overlay:** Provides a customizable grid overlay with adjustable vertical and horizontal line counts, line thickness, value ranges, and labels to facilitate precise data interpretation.
-   **Plug-and-Play Integration:** Designed for easy adoption and seamless integration into various projects.
-   **High-Resolution Data Display:** Supports averaging of data inputs and customizable display resolutions to balance precision and performance according to project requirements.
-   **Scalability:** Scales smoothly and maintains visual fidelity across various aspect ratios.
